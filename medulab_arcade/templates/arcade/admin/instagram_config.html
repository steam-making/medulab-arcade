🔧 설정 방법 (Instagram API with Instagram Login)
  1. 인스타그램 계정 설정에서 "Instagram Apps and Websites" → 이 사이트용 토큰 생성 화면으로 이동해 액세스 토큰을 발급받습니다.

  4. 이 토큰은 앱 ID/시크릿 없이도 만료 7일 전부터 자동으로 새 토큰으로 갱신됩니다.
